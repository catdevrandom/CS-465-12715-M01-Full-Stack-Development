# Travlr Getaways (CS 465)

1. Start MongoDB.
2. In this folder: npm install, then node app_api/models/seed.js, then npm start (http://localhost:3000)
3. In app_admin: npm install, then ng serve (http://localhost:4200)
4. Create an admin user: POST http://localhost:3000/api/register with JSON {"name","email","password"}, then log in through the SPA.
